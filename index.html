Why SwarlexBattery

Honest numbers

A level is shown only when the device itself answered. Rough readings are marked as approximate.

Small and quiet

One small program, about 10 MB of memory. No services, no vendor apps, no account.

Low battery alerts

Windows notifications when a battery runs low, held back until your full-screen game is over.

Time left

An estimate of the hours left, learned from how fast each device drains.

Updates itself

New versions come from GitHub with one click, each checked against its SHA-256.

Your language, your theme

English, Türkçe, Deutsch, Español and Italiano. Light or dark, like your taskbar.

Install

  1. Download SwarlexBattery-Setup.exe and run it.
  2. It installs for your user only. No administrator rights are needed.
  3. The icon appears next to the clock: left click for details, right click for the menu.

Prefer no installer? SwarlexBattery.exe from the release page runs as it is. Windows SmartScreen may warn the first time because the files are new; every release is built from the public source by GitHub Actions (code signing policy).
